\caption{System architecture. (a)~Admitted flows $f_1$ (class 0) via SW$_5$ and $f_2$ (class 1) via SW$_6$ and a new class-0 request $f$ share output port $p$. (b)~At $p$, frames are classified by priority into FIFO queues; the strict-priority (SP) selector serves class 0 first but cannot preempt a class-1 frame already in transmission, which is the $L_{lo}$ term of~\eqref{eq:hop}. (c)~A proposed change is committed only if the gate's certificate passes the independent checker, which also reads the flow database (C0); a rejection returns the violated flows to the proposer. Our proposer is greedy: requests in arrival order, never revisited.}
